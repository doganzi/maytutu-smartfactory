# 성적서·검교정 서류 관리 — 실무자 안내

> 대상: 스마트팩토리 앱을 쓰는 제조관리·작업원
> 작성 2026-08-07 · **배포 완료 — 지금 바로 쓸 수 있습니다**
> 앱에 안 보이면 화면을 새로고침하거나 앱을 껐다 켜주세요 (이전 버전이 남아 있을 수 있습니다)

---

## 한 줄 요약

**부족한 서류가 앱에 뜨고, 앱에서 바로 사진·PDF를 올립니다.** 구글 드라이브에 따로 들어갈 일이 없습니다.

---

## 1. 어디서 보나

두 군데서 보입니다.

**① 홈 화면** — 부족한 서류가 있으면 「📂 챙겨야 할 서류」 목록이 뜹니다. 앱을 켤 때 알림도 함께 뜹니다.

**② 더보기 → HACCP 기준 관리 → 「성적서」 탭** — 여기가 본판입니다. 제품별·기기별로 무엇이 있고 무엇이 없는지 한눈에 보입니다.

| 표시 | 뜻 |
|---|---|
| 🟢 보유 | 원본 파일이 드라이브에 있음 |
| 🔴 없음 | 폴더는 있는데 파일이 없음 |
| 🔴 폴더없음 | 폴더부터 없음 (올리면 자동으로 만들어집니다) |

---

## 2. 올리는 법

1. 성적서 탭에서 **올릴 항목을 눌러 펼칩니다** (예: `1.물반죽` → `원재료 시험성적서`)
2. **「＋ 올리기」** 를 누릅니다
   - 자재별 버튼이 따로 있으면(`＋ 계란`, `＋ 콩기름`) 해당 자재 버튼을 누르세요
3. **카메라로 찍거나 파일을 고릅니다**
   - 아이폰 사진 그대로 올려도 됩니다 (자동 변환)
   - PDF도 됩니다
   - PC에서는 붙여넣기(Ctrl+V)·끌어다 놓기도 됩니다
4. 올라가면 **유효기한을 물어봅니다 — 여기가 제일 중요합니다**

### ⚠️ 유효기한을 넣어야 알람이 옵니다

파일만 올리고 **「건너뛰기」를 누르면 파일은 저장되지만 만료 알람이 오지 않습니다.**
성적서에 적힌 유효기한을 보고 그대로 입력해 주세요.

- **품목명** — 자재 이름 (예: 계란, 적팥앙금S)
- **발행일 / 유효기한** — 성적서에 적힌 날짜
- 발행기관·성적서번호는 선택 (있으면 넣어주세요)

기기 검교정은 **검교정 실시일 + 차기 예정일**을 물어봅니다. 차기 예정일을 넣어야 다음에 알람이 옵니다.

### 앙버터 호두과자 — 부재료·완제품 시험성적서 없음

완제품 시험성적서는 **아직 검사를 안 받은 것**으로 보입니다. 받으면 올려주세요.
폴더가 없어도 그냥 「＋ 폴더 만들고 올리기」 누르면 됩니다.

### 등록된 성적서에 원본 링크가 빠진 것

시트에는 있는데 파일이 안 붙어 있는 성적서가 있으면 「원본 링크 없음」으로 뜹니다. 해당 자리에 원본을 올려주세요.

## 4. 알람은 언제 오나

- **유효기한 30일 전부터** 알립니다 (성적서·검교정 동일)
- 만료되면 빨간색으로 바뀝니다
- 앱을 켤 때 알림이 뜨고, 홈 화면 카드에도 건수가 표시됩니다

즉 **유효기한만 제대로 넣어두면, 만료 한 달 전에 앱이 먼저 알려줍니다.**

---

## 5. 주의할 점

**갱신은 새로 올리는 겁니다.** 기존 파일을 지우지 마세요 — HACCP 기록은 2년 보관이라 이전 성적서도 이력으로 남아야 합니다. 새 성적서를 올리면 그게 최신본이 되고 예전 것은 그대로 남습니다.

**앱에 삭제 기능은 없습니다.** 잘못 올렸으면 관리자에게 말씀해 주세요.

**「마미만쥬믹스」와 「앙브레드전용믹스」는 다른 자재입니다.** 성적서를 서로 바꿔 올리면 입고검사 근거가 어긋나 심사에서 문제가 됩니다. 폴더 이름을 확인하고 올려주세요.

**골드후라잉**은 지금 안 쓰는 자재라 새 폴더에 올리지 않습니다.

## 6. 잘 안 될 때

| 증상 | 조치 |
|---|---|
| 「인증이 만료되었습니다」 | 자동으로 다시 로그인됩니다. 잠시 기다렸다가 다시 시도 |
| 문서 현황이 「확인 중…」에서 안 넘어감 | 「새로고침」 버튼을 누르세요. 그래도 안 되면 인터넷 연결 확인 |
| 문서 현황이 안 뜸 | 드라이브 조회만 실패한 것이고 성적서 목록·등록은 그대로 됩니다 |
| 올렸는데 목록에 안 보임 | 「새로고침」을 누르세요 |
| 사진을 못 고름 (아이폰) | 「＋ 올리기」 글자를 직접 눌러야 합니다 |

---

## 7. 요약 — 이것만 기억하세요

1. **홈이나 성적서 탭에서 빨간 항목을 찾는다**
2. **펼쳐서 「＋ 올리기」로 사진·PDF를 올린다**
3. **유효기한을 꼭 입력한다** ← 안 넣으면 다음 알람이 안 온다
4. **기존 파일은 지우지 않는다** (2년 보관)
