## 2. 원인

**클라우드 온도데이터 수집 서비스(Tuya IoT Core)의 구독 기간 만료.**

- 서비스 유효기간: 2026-06-11 19:43:53 ~ **2026-07-11 19:43:53 만료**
- 만료 직후부터 온도 조회 API가 `IoT Core service subscription has expired` 오류를 반환
- 온도센서 자체는 **정상 작동**하였으며, 냉동설비 운전에도 이상 없었음
- 기록 시스템은 10분 주기로 계속 동작하였으나 **온도값만 공란으로 적재**됨

> 설비 고장이나 온도 이탈이 아니라, **기록 전송 경로(클라우드 구독)의 만료**로 인한 기록 누락임.

## 3. 인지 지연 사유 (개선 대상)

기록 시스템이 오류를 내부적으로 처리하여 **행은 계속 생성**되었고, 화면상 판정이 `적합`으로 표시되어 이상을 조기에 인지하지 못함.

## 5. 조치 내역

### 5-1. 즉시 조치 (완료)
- Tuya IoT Core 구독 연장 → **2026-07-18 17:20 자동수집 정상 복구** 확인
- 복구 후 온도 정상 기록 확인 (냉동창고 −20.1℃ / 냉장고1 3.3℃)

### 5-2. 기록 회수 (백필)
- 온도센서 클라우드에 보존된 이력을 조회해 공백 구간 기록을 **사후 보완 기재**
- 회수 결과: 냉장고1 ______건 / 냉동창고 ______건  **[확인필요 — 최종 실행 후 기재]**
- 회수 기록은 원본과 구분되도록 **보완기재(backfill) 표시** 후 저장
- 센서 클라우드 보관기간(약 7일) 경과분은 **회수 불가** → 해당 구간은 공란 유지하고 본 사유서로 갈음

### 5-3. 시스템 개선 (완료)
1. 온도 결측 행을 `적합`이 아닌 **`결측`(경고)** 으로 표시 — 기록부·PDF 동일 적용
2. 온도 미확인 시 출하 판정을 **`온도미확인`** 으로 사실대로 기록
3. **연속 결측 30분 이상 시 화면 상단 경보 배너** 표시 (조기 인지)
